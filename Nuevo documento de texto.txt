Descarga el código.

Crea un archivo .env basado en .env.example con tus datos de Firebase.
Ejecuta npm run dev y abre http://localhost:3000.
La aplicación está ahora lista para ser personalizada, impresa y utilizada en cualquier entorno.

Aquí tienes la guía paso a paso para configurar tu archivo .env en tu computadora local:
Paso 1: Localiza la carpeta del proyecto
Una vez que hayas descargado o exportado el código de la aplicación a tu computadora, abre la carpeta principal (donde verás archivos como package.json, README.md, etc.).
Paso 2: Crea el archivo .env
Tienes dos formas de hacerlo:
Opción A (Recomendada): En tu editor de código (como VS Code), haz clic derecho en la carpeta raíz y selecciona "Nuevo archivo". Ponle el nombre exacto: .env (asegúrate de incluir el punto al principio y que no tenga ninguna extensión como .txt).
Opción B (Desde el explorador de archivos): Haz una copia del archivo .env.example y cámbiale el nombre a simplemente .env.
Paso 3: Copia y pega los valores
Abre el nuevo archivo .env que acabas de crear y pega el siguiente bloque de texto (estos son tus datos reales de Firebase que están funcionando ahora mismo):
code
